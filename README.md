# My Website

A simple static website built with HTML, CSS, and JavaScript.

## Files

- `index.html` — page structure
- `style.css` — page styling
- `script.js` — button interaction

## Run locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

In your GitHub repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
